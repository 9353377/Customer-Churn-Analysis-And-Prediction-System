# ?? Customer Churn Analysis and Prediction System

A Machine Learning project that predicts customer churn using customer behavior and telecom service data. The project applies data preprocessing, exploratory data analysis (EDA), feature engineering, and multiple machine learning algorithms to identify customers who are likely to discontinue telecom services.

## ?? Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Visualization
- Machine Learning Model Training
- Model Evaluation & Comparison
- Customer Churn Prediction

## ?? Key Insights

- Customers with shorter tenure are more likely to churn.
- High monthly charges increase churn probability.
- Long-term contracts improve customer retention.
- Customers using multiple services are less likely to churn.
